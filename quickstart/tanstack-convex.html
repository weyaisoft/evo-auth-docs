Quickstart: TanStack Start with Convex ​

This page takes you from an empty folder to a TanStack Start app on Convex where you sign up with an email address and a password and land on a signed-in page. Convex runs on your machine, so you need no Convex account, no mail service and no OAuth app.

Before you start ​

  • Node and pnpm. Use the Node version your Convex release supports; the supported versions page lists what was tested.
  • git. init refuses to run in a folder that is not a git repository, because it checks that git ignores the file it writes your secrets to.

The commands below are for a Unix shell (macOS, Linux, or WSL). Run each block as a whole. Steps 8 and 9 each need their own terminal, so keep this one for the rest.

Step 2 installs from the npm registry, so it works once Evo Auth has been published there.

The steps ​

1. Create the app ​

pnpm create @tanstack/start@0.59.61 my-app --yes
cd my-app
test -d .git || git init

--yes accepts the create command's defaults and asks nothing. The create command may end with a line saying @tanstack/intent install did not run successfully: ignore it. The last line starts a git repository only if the create command did not.

2. Install the packages ​

pnpm add convex@1.49.0 @evo-auth/core@0.1.0 @evo-auth/react@0.1.0 @evo-auth/convex@0.1.0

3. Make the local Convex deployment ​

npx convex dev --once

Convex asks Would you like to login to your account?: choose Start without an account (run Convex locally), then answer Continue? with Enter (yes). It then makes a deployment on your machine, writes VITE_CONVEX_URL and VITE_CONVEX_SITE_URL into .env.local, and exits. init needs this deployment, because it sets the auth variables on it.

4. Run init ​

pnpm exec evo-auth init --stack tanstack-convex

init writes these files and refuses, changing nothing, if any of them already exists:

  • .env.local gets the signing keys and secrets it made. No other file holds a secret.
  • evo-auth.config.ts: email and password sign-up, no provider, and a development sender that prints each code in the npx convex dev terminal instead of sending mail.
  • convex/convex.config.ts, convex/auth.config.ts, convex/http.ts and convex/auth.ts: the Evo Auth component, its routes and its email job.
  • src/lib/evo-auth.server.ts and src/routes/auth/$.ts: the proxy that relays /auth/* from your app to Convex.
  • src/middleware/evo-auth.ts, and src/start.ts if your app has none. If your app already has a src/start.ts, init prints the one line to add to it.
  • src/components/evo-auth-root.tsx, with the Convex provider inside it, and src/routes/sign-in.tsx and src/routes/sign-up.tsx.

It then sets the auth variables on your local deployment with npx convex env set, and prints the edits it does not make itself. Steps 5 to 7 are those edits.

5. Import the root component ​

In src/routes/__root.tsx, add this line with the other imports:

tsx
import { EvoAuthRoot, loadAuthState } from "../components/evo-auth-root";

6. Add the loader ​

In the same file, add these two lines to the options object that createRootRoute is called with, beside head and shellComponent:

tsx
loader: () => loadAuthState(),
shouldReload: false,

7. Wrap the page ​

In the same file, find the <body> in the root document. It renders {children}. Wrap that in EvoAuthRoot, and leave <Scripts /> after it:

tsx
<EvoAuthRoot>{children}</EvoAuthRoot>

8. Start Convex ​

In a second terminal, in my-app:

cd my-app
npx convex dev

It pushes your convex/ folder to the local deployment and keeps running. This is the terminal where the sign-up code appears.

9. Start the app ​

In a third terminal, in my-app:

cd my-app
pnpm dev

10. Sign up ​

Open http://localhost:3000/sign-up. Enter an email address and a password of at least 15 characters that is not a well-known phrase (the form shows both rules: it refuses a password found in a known data breach), and press Create account. The page asks for a code and stays on the same page: leave it open. The terminal from step 8 has printed a message with the code: type it in on that page and press Create account again. The page then says You are signed in.

If something goes wrong ​

  • init says a file already exists. Move that file aside and run it again. init never overwrites or edits a file.
  • init says the env file is not ignored by git. Add .env.local to .gitignore, then run it again.
  • init says the convex package is missing. Run step 2, then step 3, then init again.
  • init could not set a variable on Convex. Fix the Convex error it printed. It names each variable that was not set, and the value is in .env.local.
  • No code appears. The code is printed only by the terminal that runs npx convex dev, never the one that runs pnpm dev.
